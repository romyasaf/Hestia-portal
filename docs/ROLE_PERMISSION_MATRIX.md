# Role Permission Matrix (MVP)

## Admin

- Full access to all modules
- Manage users, roles, and company settings
- Approve accounting adjustments

## Staff

- View/update assigned tickets and jobs
- Create expenses and inventory transactions
- View financial data based on assigned scope

## Tenant

- Create/view own maintenance tickets
- View lease, invoices, and payments
- Submit service/renovation requests

## Property Owner

- View owned properties, units, lease summaries
- View maintenance and job status for owned assets
- Submit renovation/service requests

## Contracting Client

- View own jobs, estimates, invoices, and payments
- Approve estimates
- Track project updates
